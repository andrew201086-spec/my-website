# Порядок работы с файлами сайта

## Правило

**Истина — хостинг, а не папка на диске.** Любая локальная копия устаревает в тот
момент, когда правка заливается через Plesk мимо неё.

1. Перед работой скачать свежий архив с хостинга
   (Plesk -> Диспетчер файлов -> корень -> Добавить в архив -> скачать).
2. Сверить с `Harmony Dental Clinic/`: количество слов на 2-3 страницах и список файлов.
3. Правки делать только в `Harmony Dental Clinic/`.
4. Перед правкой боевого файла — копия в `_work/backups/ГГГГ-ММ-ДД_имя.расширение`.
5. Залить. С этого момента папка снова равна продакшену.

Никогда не редактировать файлы в Загрузках и не держать единственную копию
доработанной страницы вне папки сайта.

## Гигиена продакшен-папки

По `CLAUDE.md` в `Harmony Dental Clinic/` должны быть только файлы, доступные
по URL. В июньской версии там лежали `semantychne-yadro-*.xlsx`,
`SEO-аудит_HarmonyClinic.pdf`, `Harmony_Clinic_Roadmap.pdf`,
`plan-vprovadzhennya-semyadra.docx`, `gemini.md`, `skills-lock.json`,
`reviews_mockup.html`, `footer_template.html`, папки `scratch/`, `docs/`, `scripts/`.
В новой папке их нет — они остались в бэкапе июньской версии.
Если что-то из этого нужно, переносить в `_work/`, а не обратно в продакшен.
