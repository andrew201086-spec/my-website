## 1. Что было не так

| Проблема | Влияние |
|---|---|
| **479 слов** видимого текста | Критично. Топ-выдача по «імплантація зубів Одеса» — 1500–3000 слов. Страница физически не могла ранжироваться по среднечастотке |
| FAQ существовал **только в JSON-LD**, на странице его не было | Разметка без соответствующего видимого контента — нарушение правил Google, риск игнора сниппета или ручных санкций |
| Нет блока про **бренды имплантов** | Терялся весь кластер «импланты Straumann / MIS / Alpha Dent Одесса» |
| Нет **костной пластики и синус-лифтинга** | Полностью терялся кластер («синус-ліфтинг Одеса ціна», «нарощування кістки») — а это высокочековые запросы |
| Нет **одномоментной имплантации** | Терялся кластер «імплантація одразу після видалення» |
| Нет **показаний / противопоказаний** | Стандартный блок у всех конкурентов в топе, влияет на полноту ответа |
| В тексте нет гео-слов (Таирова, Киевский район) | Гео было только в schema — Google слабее связывал страницу с районом |
| Нет E-E-A-T блока о враче | Медицинская тематика YMYL: без авторства/экспертизы ранжирование заметно хуже |
| Нет видимых хлебных крошек | BreadcrumbList был, визуального аналога нет |
| В FAQ упомянуты Nobel Biocare и MegaGen | Их нет в прайсе клиники — несоответствие контента и услуг |

## 3. Что осталось сделать (не автоматизируется)

1. **Цены на костную пластику и синус-лифтинг.** В тексте сейчас «рассчитывается индивидуально после КТ». Если есть прайс — добавить таблицу: это высокочековые коммерческие запросы, наличие цены заметно улучшает конверсию и поведенческие.
2. **Отзывы.** На странице их нет. `AggregateRating` намеренно НЕ добавлен — без реальных отзывов на странице это нарушение правил Google и риск санкций. Стоит вывести 3–4 отзыва именно по имплантации.
3. **Данные о враче.** Блок об Олеге Швеце написан без конкретики (образование, стаж, сертификаты, количество установленных имплантов) — не было исходных данных. Для YMYL-тематики это самый недооценённый рычаг: добавить факты.
4. **Фото процесса.** Кейсы «до/после» есть, но нет фото операционной, шаблона, сканера. Уникальные фото — сильный сигнал экспертности.
5. **Страница All-on-X.** Семантика под неё в PDF готова, страницы нет. Пока она не создана, с общей страницы имплантации на неё намеренно не ставилась ни одна ссылка.
6. **Оглавление.** Страница стала длинной — если по аналитике до блока цен не долистывают, добавить якорное меню в начале.
7. **После заливки:** переобход в Google Search Console + проверка FAQ и Breadcrumbs в тесте расширенных результатов.
